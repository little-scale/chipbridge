# Pico-family firmware releases

These UF2 binaries are distributed under GPL-2.0-only with their corresponding
source under [`../../firmware/rp2040/`](../../firmware/rp2040/).

Ready-to-flash unified USB/serial-MIDI bridge firmware. Each image supports
MIDI Clock plus transport through the `SYNC: IN24` counter and automatically
switches channel-voice messages to the console-clocked `SYNC: MIDI` takeover
protocol. They enumerate as `Chipbridge` with a `Chipbridge MIDI` port.

Every build supports an optional firmware-alive/activity LED on GP7 through a
1 kΩ series resistor. It turns on after setup, pulses off for channel MIDI, and
pulses once per quarter note while receiving MIDI Clock.

| Hardware | Firmware |
|---|---|
| Raspberry Pi Pico | [`chipbridge-pico.uf2`](chipbridge-pico.uf2) |
| Raspberry Pi Pico 2 | [`chipbridge-pico2.uf2`](chipbridge-pico2.uf2) |
| Raspberry Pi Pico 2W | [`chipbridge-pico2w.uf2`](chipbridge-pico2w.uf2) |
| Waveshare RP2040-Zero | [`chipbridge-rp2040-zero.uf2`](chipbridge-rp2040-zero.uf2) |
| Seeed XIAO RP2040 | [`chipbridge-xiao-rp2040.uf2`](chipbridge-xiao-rp2040.uf2) |

These images were built with Arduino-Pico core 5.5.1 using the default Pico SDK
USB stack. Verify downloaded files with [`SHA256SUMS.txt`](SHA256SUMS.txt).
They are generated by
[`../../tools/make-pico-release.sh`](../../tools/make-pico-release.sh), which
explicitly selects the automatic runtime role.
The serial MIDI RX pin and required opto-isolated receiver are documented in
[`../../docs/SERIAL_MIDI.md`](../../docs/SERIAL_MIDI.md).

Choose the image that exactly matches the board. Pico and Pico 2 firmware is
not interchangeable.

Fixed-role diagnostic images can be produced from the same source with the
compile-time wire-role setting described in the firmware README.
